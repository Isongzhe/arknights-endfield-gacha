# 武器池（武庫申領）規則紀錄

狀態：**已建模**（`gacha.rules.weapon`、`gacha.models.weapon`、`gacha weapon` 指令與網站的武器一節），規則編號 W1 至 W6 見 `docs/assumptions.md`。100 抽武器箱與 180 抽的第二把尚未建模。來源：專案作者 2026-09-16 的說明，以及 endfield.wiki.gg 的 Arsenal Exchange 頁面。

## 資源

- 武器池不能用合成玉直接抽，只能用武庫配額。來源：角色池轉換、活動、每週任務、大月卡、商店兌換、課金源石轉換。
- 角色池每抽到一隻角色給武庫配額：四星 20、五星 200、六星 2,000。
- 1,980 武庫配額換一次十連，不能單抽。每次十連保底一把五星武器。

## 機率與保底

| 規則 | 作者說明 | wiki |
|---|---|---|
| 六星武器機率 | 4% | 4%（另列四星 81%、五星 15%） |
| 六星中為當期 UP 的比例 | 25% | 25% |
| 40 抽 | 必出六星武器，75% 歪 | 未提 |
| 80 抽 | 必出當期 UP 武器 | 連續 7 次十連沒拿到 UP，第 8 次必出 |
| 100 抽 | 額外送六星武器箱，非當期 UP | 未提 |
| 180 抽 | 送當期 UP 武器 | 第 18 次十連給 UP |
| 之後 | 每 80 抽輪替常駐與當期 UP | 之後每 8 次十連一循環 |

- 武器池的抽數不繼承，一個武器池持續三個卡池。
- 復刻武器池「點繪申領」的累積抽數只累積到下一次同名武器池。

## 待確認

1. 40 抽的六星保底是「連續 40 抽沒出六星」的滾動計數，還是池內第 40 抽的一次性保底。兩種算法在拿到 UP 的機率上最多差 3 個百分點。
2. 80 抽的 UP 保底在提早拿到 UP 後是否失效。
3. 100 抽的武器箱與 180 抽的 UP 是否每池各一次。
4. 復刻武器池的規則是否與一般武器池相同。
